# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/ArchAstro/astroshots/security/advisories/new)
and include:

- the affected package or Astroshots app version;
- reproduction steps or a minimal fixture;
- the expected and observed impact;
- any suggested mitigation, if known.

Do not include live credentials, customer data, or screenshots containing
private information. We will acknowledge the report, investigate it, and
coordinate disclosure and a fix with the reporter.

## Supported versions

Security fixes target the latest published npm package and the latest macOS
release. Older versions may require upgrading to receive a fix.
